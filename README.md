# macOS Mouse Input Monitor

一个轻量级 macOS 菜单栏工具，用于查看当前鼠标的连接信息、活动状态和实时输入事件速率。

应用通过 macOS HID 与事件监听接口在本机统计鼠标输入，并把结果直接显示在菜单栏中，适合检查鼠标是否正常连接、是否持续产生输入，以及快速观察事件频率。

## 功能

- 自动识别当前连接的鼠标设备
- 在多只鼠标之间选择要监控的设备
- 每 0.5 秒刷新输入事件速率
- 显示 `Active` / `Idle` 活动状态
- 展示设备名称、USB/蓝牙等连接方式
- 展示设备 VID 与 PID
- 记住上次选择的鼠标
- 从菜单栏直接查看事件数并退出应用

## 隐私

所有检测均在本机完成。应用只统计鼠标事件数量和设备状态，不记录键盘输入，也不保存鼠标坐标或点击内容。

## 技术实现

- SwiftUI `MenuBarExtra` 菜单栏界面
- IOKit HID 设备发现与输入报告监听
- Core Graphics `CGEvent` 只读事件监听
- AppKit `NSEvent` 全局与本地事件监控
- `UserDefaults` 保存当前选择的设备

## 权限

为了统计其他应用中的鼠标活动，macOS 可能会要求开启“输入监控”或“辅助功能”权限。未授权时，设备信息仍可能显示，但全局事件统计可能不完整。
